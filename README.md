## 📖 О приложении

**ToDoList** — это приложение, которое каждый скачивал на своё устройство. Здесь вы можете создавать напоминания, кастомизировать интерфейс и выполнять задания.

### 💡 Чем же тогда наше приложение отличается от других?

> В нашем приложении за выполнение своих целей вы получаете **награды**. А также, когда вы что-то сделали, вы можете **прикрепить результат работы** (фото, текст).

---

## 🗂 Структура

Приложение состоит из **5 основных страниц**:

| # | Страница | Описание |
|---|----------|----------|
| 1 | 🔑 Регистрация | Создание нового аккаунта |
| 2 | 🔐 Логин | Вход в существующий аккаунт |
| 3 | 📋 To Do List | Управление заданиями |
| 4 | ⚙️ Настройки | Кастомизация интерфейса |
| 5 | 👤 Профиль | Просмотр наград и статистики |

## 🚀 Установка и запуск

```bash
# 1. Клонируем приложение на ваше устройство
git clone <URL_РЕПОЗИТОРИЯ>

# 2. Переходим в папку проекта
cd my-app

# 3. Устанавливаем необходимые библиотеки
npm i

# 4. Запускаем приложение в режиме разработки
npm run dev
```

> ⚠️ **Перед началом работы вам нужно зарегистрироваться.**
> Введите `username` и `password` и нажмите **«Зарегистрироваться»**.

После чего приложение полностью готово к эксплуатации. 🎉

## ❓ FAQ по частым вопросам

<details>
<summary><b>«Что делать, если данные не сохранились?»</b></summary>

К сожалению, мы не можем с этим помочь — нужно заново редактировать.

</details>

<details>
<summary><b>«Не получается зарегистрироваться»</b></summary>

Вероятнее всего, username, который вы используете, уже занят.

</details>

<details>
<summary><b>«Что делать, если забыл свой пароль?»</b></summary>

При регистрации вам выдаётся уникальный ключ, с помощью которого вы можете изменить пароль. **Никому не показывайте свой ключ доступа.**

</details>

<details>
<summary><b>«Приложение не запускается»</b></summary>

Проверьте, что вы находитесь в папке `my-app` и что установлены все зависимости (`npm i` или `npm install`). Если приложение так и не заработало — напишите в поддержку.

</details>
